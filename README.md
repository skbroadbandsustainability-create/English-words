# english-words

영어 단어 놀이터

아이가 책 사진을 찍어 올리면 사진 속 영어 단어를 자동으로 모아주고, 카드로 외우고 퀴즈로 확인하는 앱이에요.

## 주요 기능

- **단어 추가**: 책 사진을 올리면 브라우저 안에서 글자를 읽어(OCR) 영어 단어를 뽑아내고, 무료 사전 API로 뜻·발음·유의어·반의어를 자동으로 채워줘요. 복수형(cats)·과거형(walked)·비교급(happier) 같은 변형은 원래 단어(cat, walk, happy)로 되돌려서 다시 찾아보기 때문에, 사전에 더 잘 걸려요. 단어를 직접 타이핑해서 추가할 수도 있어요.
- **카드**: 단어 카드를 눌러 뒤집으면 뜻과 유의어/반의어가 나와요. 🔊 버튼을 누르면 발음을 들을 수 있어요.
- **테스트**: 방금 새로 등록한 단어만 나오는 "새 단어 테스트"와, 지금까지 모은 모든 단어로 보는 "전체 테스트"가 따로 있어요.
- **단어장**: 등록한 모든 단어를 날짜별로 모아보고, 수정·삭제할 수 있어요.
- **기록**: 연속 학습일, 모은 단어 수, 테스트 점수 변화, 자주 틀리는 단어를 확인해요.

모든 데이터는 기기(브라우저)에 안전하게 저장돼요. 서버나 API 키가 전혀 필요 없는, 완전히 무료인 방식으로 만들었어요.

> 참고: 사진 속 글자 인식은 브라우저 OCR이라 사진이 비스듬하거나 폰트가 화려하면 가끔 잘못 읽을 수 있고, 사전에 아예 없는 단어(고유명사 등)는 뜻을 직접 입력해야 할 수 있어요. 그런 경우 검토 화면에서 바로 고쳐서 저장하면 돼요.

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # 린트 검사
```

React + TypeScript + Vite + Tailwind CSS로 만들었고, 태블릿 화면에 맞춰 반응형으로 디자인했어요.
